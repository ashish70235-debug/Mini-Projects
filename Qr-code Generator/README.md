\# QR Code Generator



\## About

A mini project that generates QR codes and a text file(URL witten) from user-provided URLs.



\## Features

\- Generate QR codes

\- Accept URLs

\- Download the generated QR code



\## Technologies Used

\- JavaScript

\- node.js

\- Packages \& modules(inquirer, qr-image, fs module)



\## How to Run

1\. Clone or download this repository.

2\. Open the project folder.

3\. run app.js by command node app.js
